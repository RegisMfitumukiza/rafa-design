# Navigation Philosophy

## Purpose

Navigation is not simply a collection of links.

For the RAFA Design website, navigation is part of the architectural experience.

It introduces visitors to the studio, encourages exploration, and establishes the rhythm of the website.

The navigation should feel carefully designed, calm, and intentional—not like a conventional website menu.

Every navigation decision should reinforce the studio's identity through simplicity, composition, typography, motion, and storytelling.

---

# Philosophy

The website should never feel like a traditional corporate website.

Visitors should experience the architecture before they think about navigation.

Projects, imagery, space, and storytelling remain the primary focus.

Navigation exists to guide exploration—not compete for attention.

The navigation system should feel closer to the table of contents of an architectural publication than the navigation bar of a business website.

---

# Navigation Principles

Every navigation decision should follow these principles.

• Minimal

• Editorial

• Quiet

• Spacious

• Intentional

• Predictable

• Accessible

• Performance-first

• Memorable

Navigation should support the experience rather than dominate it.

---

# Navigation Hierarchy

The navigation system consists of four connected layers.

1. Minimal Header

2. Fullscreen Navigation

3. Footer

4. Search

These are not separate systems.

They are different representations of the same information architecture.

---

# The Minimal Header

The header should remain visually lightweight.

Its purpose is orientation rather than navigation.

Recommended elements

• Studio Logo

• Menu Button

• Theme Toggle

• Optional utilities

Avoid placing numerous navigation links inside the header.

The content should always remain visually dominant.

---

# Fullscreen Navigation

The fullscreen navigation is the primary navigation experience.

Opening it should feel like opening an architectural publication.

The layout should prioritize:

• Typography

• Composition

• Whitespace

• Editorial rhythm

• Exploration

Visitors should feel invited to browse rather than rushed toward a destination.

---

# Editorial Layout

The fullscreen navigation should use an editorial grid.

Avoid centered corporate layouts.

Instead, use:

• Multiple columns

• Uneven composition

• Large negative space

• Strong typography hierarchy

• Carefully balanced spacing

The interface should feel curated rather than generated.

---

# Information Architecture

Primary destinations

• Projects

• Studio

• Services

• Process

• Journal

• Contact

Supporting destinations

• Careers

• Awards

• Publications

• Sustainability

• News

Supporting content should remain visually secondary.

---

# Search Philosophy

Search is part of navigation.

It should not exist as a disconnected feature.

Visitors should immediately understand they can search projects, journal articles, and services directly from the fullscreen navigation.

Search should feel integrated into the editorial layout.

---

# Navigation and Footer Relationship

The fullscreen navigation and the footer should never be designed independently.

They represent different views of the same information architecture.

The footer is the condensed version.

The fullscreen navigation is the expanded version.

Together they create one continuous navigation experience.

The footer concludes exploration.

The fullscreen navigation begins exploration.

---

# One Information Architecture

Every navigation surface should originate from one shared content structure.

That structure powers:

• Header

• Fullscreen Navigation

• Footer

• Search

• Sitemap

• Breadcrumbs

• Future CMS navigation

There should never be duplicate navigation systems.

This guarantees consistency, maintainability, and scalability.

---

# Footer Philosophy

The footer is not simply the end of the page.

It is the final chapter of the visitor's journey.

Rather than ending abruptly, it gently encourages further exploration.

The footer should include:

• Additional navigation

• Contact information

• Social links

• Studio information

• Legal pages

It should feel calm, editorial, and spacious.

---

# Expanding Navigation Concept

The footer and fullscreen navigation should feel like one continuous interface.

Think of the relationship like this.

Footer

↓

Expands

↓

Fullscreen Navigation

↓

Collapses

↓

Footer

Visitors should subconsciously recognize this relationship.

The menu should feel like unfolding the footer into a richer editorial experience.

Likewise, arriving at the footer should feel like discovering a condensed version of the same navigation system.

This continuity becomes part of the RAFA Design identity.

---

# Motion Philosophy

Navigation motion should support orientation.

Never animate for decoration.

Recommended sequence

Menu Click

↓

Background Softens

↓

Overlay Appears

↓

Navigation Columns Reveal

↓

Primary Links Reveal

↓

Secondary Links Reveal

↓

Search Appears

↓

Featured Content Reveals

Closing follows the reverse order.

Animations should generally complete within 500–700ms.

---

# Featured Content

The fullscreen navigation may include:

• Featured Project

• Latest Journal Article

• Studio Philosophy

• Awards

• Selected Imagery

Featured content should encourage exploration without distracting from navigation.

---

# Responsive Philosophy

The navigation philosophy remains identical across all screen sizes.

Desktop

↓

Tablet

↓

Mobile

Only layout and spacing change.

The navigation experience remains consistent.

---

# Accessibility

Navigation must be fully accessible.

Requirements

✓ Keyboard navigation

✓ Visible focus indicators

✓ Focus trapping

✓ Escape closes overlay

✓ Screen reader support

✓ Reduced motion support

✓ Semantic landmarks

✓ Sufficient color contrast

Accessibility is a core requirement, not an enhancement.

---

# What to Avoid

Do not implement:

✗ Large corporate navigation bars

✗ Heavy sticky headers

✗ Dropdown-heavy menus

✗ Competing navigation systems

✗ Decorative animations

✗ Cluttered layouts

✗ Navigation that competes with project imagery

✗ App-style sidebars

Navigation should disappear into the experience.

---

# Success Criteria

The navigation is successful when visitors:

✓ Understand the studio structure immediately

✓ Feel encouraged to explore

✓ Never feel overwhelmed

✓ Reach any destination effortlessly

✓ Experience smooth transitions

✓ Recognize consistency between the header, menu, and footer

✓ Remember the navigation as part of the architectural experience

---

# Long-Term Vision

The RAFA Design navigation should establish its own identity.

It should not imitate BIG, Snøhetta, or other architecture studios.

When closed, it should be almost invisible.

When opened, it should feel like entering the studio's editorial archive.

The navigation should transform from a minimal interface into an immersive exploration space while remaining elegant, accessible, fast, and timeless.

---

# Navigation Experience Flow

Navigation is not a collection of isolated components.

It is a continuous journey that accompanies visitors throughout the website.

Rather than designing the header, fullscreen navigation, footer, and search independently, they should be viewed as different states of the same navigation system.

## System Relationship

Navigation System

├── Minimal Header

├── Fullscreen Navigation

├── Footer

└── Search

↓

Shared Information Architecture

Everything should originate from one navigation model.

Header, menu, footer, search, sitemap, breadcrumbs, and future CMS should remain synchronized.

## AI Implementation Rules

Whenever navigation is modified, the AI must:

• Treat the header, fullscreen navigation, footer, and search as one connected system.

• Never redesign one navigation surface without considering the others.

• Preserve the editorial philosophy throughout the experience.

• Reuse the shared navigation data model.

• Maintain consistency with the Design System, Page Architecture, and Component Architecture.

## Final Goal

Visitors should never remember clicking a menu.

They should remember discovering the studio.

The navigation should feel architectural in its composition, editorial in its presentation, and effortless in its usability.

It should become part of the identity of RAFA Design rather than simply a way to move between pages.
